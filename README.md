# Guardrail Trader

Track A agent for the Binance Agent OS Mini Hackathon.

Category: Data and Analysis

What it does:
- Reads live Binance market data through MCP
- Checks the agentic sub-account
- Gives a short risk note
- Does not trade until the user says yes

How to run:
1. Open this folder in VS Code
2. Start the Binance MCP server in .vscode/mcp.json
3. Open Copilot Chat in Agent mode
4. Paste the prompt from DEMO.md
